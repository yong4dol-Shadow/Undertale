# UNDERTALE : 갈라진 대지

**소닉 언리쉬드의 줄거리만 빌려서 만든, 언더테일 방식의 브라우저 RPG.**

행성이 일곱 조각으로 갈라지고, 지저의 어둠이 깨어난다.
주인공은 밤이 되면 다른 모습이 되는 저주를 얻고,
기억을 잃은 작은 빛과 함께 일곱 신전에 원석을 되돌리러 떠난다.

전투는 언더테일 그대로다. 붉은 SOUL로 탄막을 피하고,
**FIGHT / ACT / ITEM / MERCY** 중에서 고른다.
모든 적은 죽이지 않고 넘어갈 수 있고, 마지막 상대도 마찬가지다.
그 선택에 따라 엔딩이 갈린다.

---

## 실행

외부 라이브러리도, 빌드 도구도, 이미지·음원 파일도 없다. 그래픽과 소리는 전부 코드로 만든다.

```bash
# 1. 그냥 열기
index.html 을 브라우저로 열면 된다.

# 2. 로컬 서버로 열기 (저장 기능이 더 안정적)
python3 -m http.server 8000
# → http://localhost:8000
```

## 조작

| 키 | 기능 |
|---|---|
| 방향키 / WASD | 이동 · SOUL 조작 · 메뉴 선택 |
| Z / Enter | 확인 · 공격 · 대화 넘기기 |
| X / Shift | 취소 · 전투 중 느리게 이동 |
| C | 메뉴 (물품 / 스탯 / 도움말) |

모바일은 화면 왼쪽을 스와이프해 이동, 오른쪽을 탭해 확인.

## 게임 시스템

### 낮과 밤 — 두 개의 형상
| | 낮의 형상 | 밤의 형상 |
|---|---|---|
| SOUL | 빨강 | 보라 |
| 이동 | 빠름 | 느림 |
| 공격 | 단발 정타 | **3연격** + 공격력 보정 |
| 방어 | 보통 | 받는 피해 25% 감소 |
| 전투 상자 | 좁음 | 넓음 |

이야기 진행에 따라 해가 지고 뜨며 자동으로 바뀐다.

### 탄막 규칙
- 하얀 탄: 닿으면 아프다.
- **파란 탄**: 움직이고 있을 때만 아프다. (멈추면 통과)
- **주황 탄**: 멈춰 있을 때만 아프다. (움직이면 통과)
- 붉은 선은 예고. 그 다음에 오는 것이 진짜다.

### 자비
적마다 고유한 ACT가 있다. 조건을 채우면 **MERCY**의 「봐주기」가 노랗게 빛난다.
아무도 죽이지 않고 끝까지 갈 수 있으며, 최종전에서도 「자장가」를 네 번 불러 주면
녹스를 죽이는 대신 **재울 수 있다.** 엔딩은 그때 갈린다.

## 이야기 (7장 + 프롤로그)

| 장 | 무대 | 사건 |
|---|---|---|
| 프롤로그 | 오보이드 궤도 요새 | 함정. 일곱 원석의 힘으로 행성이 갈라지고 **녹스**가 깨어난다. 어둠 한 줄기가 SOUL에 박힌다 |
| 1장 | 미르카 해안마을 | 기억을 잃은 **코코**와 만난다. 첫 밤, 첫 변신, 첫 신전 |
| 2장 | 스파고니아 대학도시 | **바질 박사**가 가이아 문서를 읽어 준다. 낮의 룩스와 밤의 녹스. 박사 납치와 구출 |
| 3장 | 홀로스카 설원 | 얼음 아래 신전. **다크 모라이**. 코코가 "무언가를 재운" 기억을 떠올린다 |
| 4장 | 아다바트 수상마을 | 지키는 법을 잊은 **넝쿨 뱀**. 여섯 조각 |
| 5장 | 샤말 사막 | 마지막 신전에서 오보이드가 원석과 코코를 빼앗아 간다 |
| 6장 | 오보이드랜드 | 균열 위의 유원지. **오보이드 드라군**. 구출 직후 녹스가 완전히 깨어난다 |
| 7장 | 균열 아래 | 닿지 않는 싸움 → 코코가 **룩스**로 각성 → 일곱 원석과 함께 최종전 |

### 원작 대응
| 소닉 언리쉬드 | 이 게임 |
|---|---|
| 웨어호그 변신 | 밤의 형상 (전투 방식이 통째로 바뀐다) |
| 칩 / 라이트 가이아 | 코코 / 룩스 |
| 닥터 에그맨 | 닥터 오보이드 |
| 다크 가이아 | 녹스 |
| 카오스 에메랄드 7개 | 프리즘 원석 7개 |
| 가이아 신전 · 대륙 복원 | 일곱 신전 · 조각 되돌리기 |
| 피클 교수 | 바질 박사 |
| 에그맨랜드 · 에그 드라군 | 오보이드랜드 · 오보이드 드라군 |

이름과 인물은 전부 새로 만들었고, 빌린 것은 **이야기의 뼈대뿐**이다.

## 구조

```
index.html            스크립트 로드 순서
css/style.css         화면 스케일링
js/core/
  util.js             수학 · 텍스트 줄바꿈 · 한글 조사 처리
  input.js            키보드 / 터치
  audio.js            WebAudio 효과음 + 10곡짜리 칩튠 시퀀서
  sprite.js           문자열 도트 스프라이트 렌더러 (캐시 포함)
  dialog.js           타자기 대화 상자 · 선택지
  game.js             루프 · 씬 스택 · 세이브 · 컷신 감독(제너레이터)
js/data/
  sprites.js          51종 도트 그래픽 (전부 텍스트로 그림)
  items.js            회복품 · 무기 · 방어구
  patterns.js         탄환 객체 + 18종 공격 패턴
  enemies.js          12종 적: 스탯 · ACT · 대사 · 자비 조건
  maps.js             20개 방 · 타일 렌더러 · 12종 테마
  story.js            프롤로그부터 엔딩까지 전체 컷신
js/scenes/
  title / naming / overworld / battle / menu / gameover / ending
js/main.js            부트스트랩
```

컷신은 제너레이터로 쓴다:

```js
story.ch1_night = function* () {
  yield* S.say('* 해가 언덕 뒤로 넘어간다.');
  yield* setForm('night');
  yield* S.say({ text: '“으아아아! 뭐야! 뭐야 너!“', face: 'coco' });
  yield* S.battle('shard');
};
```

비상업 팬 게임이다.
